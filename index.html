Alur Penurunan Rumus

1. Dimensi Trapesium Saat Ini
Sisi Atas (a) = 0 kotak | Sisi Bawah (b) = 0 kotak | Tinggi (t) = 0 kotak
2. Duplikasi & Rotasi Balik
Trapesium oranye transparan diputar balik 180° untuk digabungkan di bagian samping.
3. Terbentuk Jajar Genjang Sempurna
Gabungan keduanya membentuk Jajar Genjang baru dengan dimensi:
Alas Jajar Genjang = a + b = 0 + 0 = 0 kotak
4. Menghitung Luas Gabungan Bangun
Luas Jajar Genjang = Alas × Tinggi
Luas Gabungan = 0 × 0 = 0
Maka Luas 1 Trapesium Asli Adalah:
Luas = ½ × (a + b) × t
Substitusi Angka:
Luas = ½ × 0 = 0 kotak2
